# اپ «گزارش کارکرد ماهیانه پروژه‌ها» (`worklog`)

اپی برای ثبت این‌که هر کارمند در هر روز چند ساعت روی هر پروژهٔ شرکت کار
کرده است، با ساعت کار گرفته‌شده از سیستم حضور و غیاب و خروجی اکسل در
قالب گزارش ماهیانهٔ شرکت.

---

## جریان کار

1. **ادمین پروژه‌ها را تعریف می‌کند**
   - `/worklog/projects/` (رابط داخلی) یا `/admin/worklog/project/` (جنگو)
   - نام، کد، توضیح، ترتیب نمایش و فعال/غیرفعال.

2. **کارمند ساعت‌ها را ثبت می‌کند**
   - `/worklog/` → انتخاب ماه/سال شمسی
   - ماتریس پروژه × روز؛ برای هر روز ساعت هر پروژه را وارد می‌کند.
   - ردیف **«سایر»** برای فعالیتی که پروژه‌اش تعریف نشده (با عنوان دلخواه).
   - در موبایل به‌صورت **کارت‌های روزانه** (فیلدهای هر پروژه + جمع/باقی‌مانده)
     نمایش داده می‌شود؛ دکمهٔ «نمای موبایل/دسکتاپ» هم موجود است.
   - جمع تخصیص هر روز نمی‌تواند از **حضور فیزیکی + مأموریت ریموت** بیشتر شود.
   - «ذخیره پیش‌نویس» یا «ثبت نهایی ماه».

3. **مدیر بررسی و خروجی می‌گیرد**
   - `/worklog/admin/` → وضعیت همهٔ کارمندان
   - `/worklog/admin/<user_id>/` → ماتریس فقط‌خواندنی
   - `/worklog/admin/<user_id>/export/` → اکسل همان کارمند
   - `/worklog/export/` → اکسل خودِ کاربر

## قواعد مهم

| موضوع | قاعده |
|---|---|
| منبع ساعت کار | `recognition.reports.daily_rows` (حضور + مأموریت) |
| مأموریت ریموت | ساعتش در سقف تخصیص پروژه‌ها لحاظ می‌شود و کارمند آن را روی پروژه‌ها تقسیم می‌کند |
| مأموریت شرکتی | ردیف «مأموریت شرکتی» **خودکار** از مأموریت‌های شرکتی تأییدشده پر می‌شود؛ فقط تأییدشده‌ها و غیرقابل ویرایش |
| سقف روزانه | جمع پروژه‌ها/سایر ≤ **حضور فیزیکی + مأموریت ریموت** با تلورانس ۰٫۰۱ |
| روز بدون حضور | تخصیص مجاز نیست |
| ردیف سایر | بدون عنوان، ذخیره نمی‌شود |
| ثبت نهایی | ویرایش را قفل می‌کند؛ بازگشایی با دکمهٔ «بازگشت به ویرایش» |
| دسترسی مدیر | مشاهده و اکسل؛ بدون ویرایش فایل کارمند |
| پروژه‌های غیرفعال | در ماتریس ماه‌های جدید نمی‌آیند؛ رکوردهای قبلی حفظ می‌شوند |

## ساختار

| فایل | کار |
|---|---|
| `models.py` | `Project`، `WorkLog`، `WorkLogMonth` |
| `services.py` | محاسبهٔ ماه شمسی، ساعت کار، اعتبارسنجی، ذخیره، دادهٔ گزارش |
| `excel.py` | ساخت xlsx با `openpyxl` (قالب شرکت) |
| `views.py` | صفحات کارمند/مدیر/پروژه‌ها |
| `forms.py` | فرم پروژه |
| `admin.py` | ثبت مدل‌ها در پنل جنگو |
| `templates/worklog/` | قالب‌های ماتریس دسکتاپ (`_matrix.html`)، کارت‌های موبایل (`_mobile_matrix.html`)، گزارش مدیر و مدیریت پروژه‌ها |

---

## اکسل

- ۳۱ ستون روز + ستون جمع
- هدر دوطبقه (ردیف/عنوان/روز/جمع)
- ردیف خودکار **مأموریت شرکتی (تأییدشده)**
- ردیف جمع روزانه و جمع کل (پروژه + مأموریت شرکتی)
- ردیف امضاها
- چاپ A4 افقی، RTL، فریز سطر/ستون
- خروجی: `worklog-<username>-<سال>-<ماه>.xlsx`

---

## تست

```bash
./venv/bin/python manage.py test worklog
```

پوشش تست‌ها: محاسبهٔ ماه، ساعت کار، ذخیره/اعتبارسنجی، سقف روزانه، ردیف
سایر، تفکیک **ریموت/شرکتی** و ردیف خودکار مأموریت شرکتی (و نادیده‌گرفتن
درخواست‌های در انتظار)، نمای موبایل/کارت‌ها، قفل ماه، بازگشایی، خروجی اکسل،
دسترسی مدیر و CRUD پروژه‌ها.
