# اپ «بله بات» (`balebot`)

اتصال سامانهٔ حضور و غیاب به پیام‌رسان **بله** با API رسمی
[`docs.bale.ai`](https://docs.bale.ai/).

ربات با **Long Polling** کار می‌کند؛ بنابراین نه به دامنهٔ HTTPS، نه به
پورت عمومی، و نه به وبهوک نیاز دارد. یک سرویس جدا از وب است و اگر وب
پایین بیاید، ربات مستقل ادامه می‌دهد.

---

## امکانات

### برای کارمند
- `/start` و اتصال امن حساب با **نام کاربری + رمز عبور سامانه** (گزینهٔ الف)
- مشاهدهٔ وضعیت امروز: حضور، اولین ورود، آخرین خروج، کارکرد، استراحت باز،
  مأموریت فعال و تعداد مأموریت‌های در انتظار
- ثبت مأموریت به‌صورت گفتگوی مرحله‌به‌مرحله (تاریخ/ساعت شمسی، دلیل، مقصد،
  شمارهٔ تماس) با همان اعتبارسنجی فرم سایت (همپوشانی، ۷ روز گذشته، ۳۰ روز آینده)
- فهرست ۱۰ مأموریت اخیر + لغو مأموریت‌های در انتظار
- گزارش ماه شمسی

### برای مدیر
- صف مأموریت‌های در انتظار با دکمهٔ **تأیید / رد** (رد بدون دلیل ممکن نیست)
- داشبورد امروز: حاضر، در حال حضور، خطاهای خروج
- فهرست و رفع خطاهای خروج
- مدیریت کاربران: جستجو، ساخت کاربر، ریست رمز، تغییر نقش، فعال/غیرفعال
- پیام همگانی به همهٔ حساب‌های متصل
- گزارش ماه
- **تأیید گروهی** همهٔ صف با تأیید دوم
- **آمار ربات** و **ردپای اقدامات (Audit)** با صفحه‌بندی

### عمومی (فاز ۱)
- **تنظیمات** (`/settings`): روشن/خاموش کردن اعلان مأموریت، اعلان روزانه و اخبار
- **تغییر رمز** (`/password`) داخل ربات؛ رمز خام هرگز ذخیره نمی‌شود
- **گزارش هفته** (`/week`) با تفکیک روزانه و **خروجی اکسل ماه** از داخل ربات
- **صفحه‌بندی** همهٔ لیست‌ها + **کیبورد ثابت پایین صفحه**
- **محدودیت نرخ پیام** (۳۰ پیام در دقیقه) و **آفست مقاوم** در برابر قطعی
- **خاموش/روشن کردن ربات** از تنظیمات دیتابیس بدون دیپلوی

### یادآورهای خودکار
```
cron هر ۵ دقیقه → manage.py balebot_reminders
```
- **فراموشی خروج**: بعد از ساعت پایان کار + مهلت تنظیم‌شده
- **مأموریت نزدیک**: ۱۵ دقیقه قبل از شروع مأموریت تأییدشده
- **صف تأیید**: خلاصهٔ روزانه برای مدیران
- هر یادآور با `ReminderLog` یکتا می‌شود تا دوبار ارسال نشود.

### کاربران «کاربر + مدیر» (`both`)
اگر نقش کاربر در `UserProfile` برابر `both` باشد، در منو دکمهٔ
**«ورود به حالت مدیر» / «بازگشت به حالت کاربر»** ظاهر می‌شود.
نقش فعال در `BaleAccount.active_role` ذخیره می‌شود و بخش‌های مدیریتی فقط
وقتی در دسترس‌اند که حالت فعال «مدیر» باشد.

## فایل‌ها

| فایل | کار |
|---|---|
| `models.py` | `BaleAccount` (اتصال کاربر + وضعیت گفتگو) و `BotState` (آفست update) |
| `client.py` | کلاینت HTTP سبک API بله (بدون وابستگی اضافه) |
| `handlers.py` | کل گفتگو: ورود، منوها، مأموریت‌ها، ابزارهای مدیر |
| `keyboards.py` | دکمه‌های inline |
| `services.py` | دسترسی، خلاصه‌های حضور، ساخت مأموریت |
| `management/commands/runbalebot.py` | حلقهٔ Long Polling |
| `tests.py` | ۳۳ تست با کلاینت ساختگی |

## راه‌اندازی

۱) توکن ربات را از [@botfather](https://ble.ir/botfather) بگیرید و در `.env`
(که در گیت نیست) بگذارید:

```env
BALE_BOT_TOKEN=123456789:...
BALE_API_BASE=https://tapi.bale.ai
BALE_POLL_TIMEOUT=25
```

۲) مایگریشن:

```bash
./venv/bin/python manage.py migrate balebot
```

۳) اجرای دستی:

```bash
./run_balebot.sh
```

۴) اجرای دائمی با systemd:

```bash
sudo cp balebot.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now balebot
```

یا بدون sudo با cron (همان کاری که روی این سرور انجام شده):

```cron
@reboot cd /home/kian/Attendance && sleep 20 && ./run_balebot.sh >> balebot.log 2>&1
*/2 * * * * cd /home/kian/Attendance && pgrep -f "[m]anage.py runbalebot" >/dev/null || ./run_balebot.sh >> balebot.log 2>&1
*/5 * * * * cd /home/kian/Attendance && ./run_balebot_reminders.sh >> balebot.log 2>&1
```

`run_balebot.sh` از `flock` استفاده می‌کند؛ بنابراین اجرای هم‌زمان دو نسخه
ممکن نیست.

## اتصال کاربر

1. در بله به ربات پیام `/start` بدهید.
2. نام کاربری سامانه را بفرستید.
3. رمز عبور را بفرستید (پیام رمز بعد از خواندن حذف می‌شود).
4. پس از ورود، منو بر اساس نقش شما نمایش داده می‌شود.

پس از ۵ تلاش ناموفق، ورود ۱۰ دقیقه قفل می‌شود. حساب غیرفعال اجازهٔ ورود
ندارد و اگر بعد از اتصال غیرفعال شود، ربات پیام مناسب می‌دهد.

---

## امنیت

- توکن فقط در `.env` نگهداری می‌شود (نه در گیت).
- رمز عبور هرگز ذخیره نمی‌شود؛ فقط برای `authenticate` جنگو استفاده و
  پیام آن حذف می‌شود.
- هر حساب بله به یک کاربر سامانه وصل می‌شود؛ پیام‌های مدیر فقط برای
  حساب‌هایی ارسال می‌شود که کاربرشان ادمین است.
- برای تغییر نقش/غیرفعال‌سازی سوپرادمین محدودیت وجود دارد.
- لاگ خطاها در `balebot.log`.
